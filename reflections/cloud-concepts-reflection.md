# Cloud Concepts Reflection

Cloud computing has become part of my daily life, even when I do not always notice that I am using cloud-based services. Three services I regularly use are **Messenger, Canva, and GCash**. These applications show how cloud technology can support communication, creativity, and financial transactions.

**Messenger** can be classified as **SaaS (Software as a Service)** because I use the application directly without managing its servers, operating system, or infrastructure. Its deployment model is **Public Cloud** because the service is provided over the internet to many users. **Canva** is also **SaaS** because it provides ready-to-use design tools through the web or application, while the provider manages the underlying infrastructure. It uses a **Public Cloud** deployment because its services are hosted and made available to users through the internet. **GCash** can also be considered **SaaS** from an end-user perspective because I access its financial services through an application without managing the underlying technology. Its deployment can be classified as **Public Cloud** because it delivers services to a large number of customers through internet-connected infrastructure.

Git and GitHub are also important when working with cloud projects because cloud infrastructure involves many configuration files, scripts, and resources that can change over time. Version control allows developers to record changes, compare previous versions, and restore working configurations when errors occur. GitHub makes collaboration easier by allowing team members to share repositories, create branches, review changes, and merge updates in an organized way. It also provides a history of who changed files and when the changes were made. This is especially useful for cloud projects because an incorrect configuration can affect applications, security, or resources. Overall, this activity helped me understand that cloud computing is not only about using online applications but also about managing changes carefully and working effectively as a team.
