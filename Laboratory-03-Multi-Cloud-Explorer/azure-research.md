# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, artificial intelligence, security, application development, and analytics.

Azure allows organizations to deploy applications and infrastructure using Microsoft's global cloud infrastructure. It supports Windows and Linux workloads and provides integration with many Microsoft technologies and enterprise environments.

Official Website: https://azure.microsoft.com/

Official Documentation: https://learn.microsoft.com/azure/

## Global Infrastructure

Microsoft Azure operates through a global network of cloud Regions and datacenters.

An Azure Region consists of one or more datacenters connected by a high-capacity, fault-tolerant, low-latency network. Many Azure Regions also provide Availability Zones.

Availability Zones are physically separated groups of datacenters within an Azure Region. They use independent power, cooling, and networking infrastructure to improve resilience.

Organizations can select Azure Regions based on factors such as latency, data residency, compliance, and availability requirements.

## Cloud Management Console

The Azure Portal is the web-based management interface for Microsoft Azure.

Users can use the Azure Portal to:

- Create and manage cloud resources
- Configure virtual machines
- Manage databases and storage
- Monitor applications
- Configure networking
- Manage identities and permissions
- Monitor costs and resource usage

Azure resources can also be managed using Azure CLI, PowerShell, APIs, and other tools.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides scalable virtual machines that can run Windows or Linux operating systems. Organizations can use virtual machines to host applications, websites, databases, and other workloads.

### 2. Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service. It is designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### 3. Azure SQL Database

Azure SQL Database is a fully managed relational database service based on Microsoft SQL technologies. It reduces the need to manage the underlying database infrastructure.

### 4. Azure Functions

Azure Functions is a serverless compute service that allows developers to execute code in response to events without managing servers directly.

## Three Advantages

### 1. Strong Microsoft Integration

Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft Entra ID, SQL Server, Microsoft 365, and other enterprise products.

### 2. Global Infrastructure

Azure provides a broad worldwide infrastructure with many Regions and Availability Zones, allowing organizations to design geographically distributed and resilient applications.

### 3. Enterprise and Hybrid Cloud Support

Azure provides services and tools for enterprise environments and hybrid cloud architectures, making it useful for organizations that need to connect existing on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

Azure can be used by enterprises for:

- Enterprise application hosting
- Windows Server workloads
- Database hosting
- Hybrid cloud environments
- Backup and disaster recovery
- Software development and testing
- Data analytics
- Artificial intelligence and machine learning
- Virtual desktops
- Business applications
