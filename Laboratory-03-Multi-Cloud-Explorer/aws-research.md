# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a large collection of infrastructure, storage, database, networking, security, analytics, and application services. AWS allows organizations to provision computing resources and other IT services through the internet instead of maintaining all infrastructure on-premises.

AWS provides services that support applications ranging from small websites to large enterprise systems. Its services can be accessed through the AWS Management Console, command-line tools, APIs, and SDKs.

Official Website: https://aws.amazon.com/

Official Documentation: https://docs.aws.amazon.com/

## Global Infrastructure

AWS operates a worldwide cloud infrastructure organized into Regions and Availability Zones. An AWS Region is a geographic area containing multiple isolated locations called Availability Zones.

Availability Zones are designed to provide separate infrastructure locations within a Region. Organizations can distribute workloads across multiple Availability Zones to improve availability and resilience.

AWS allows organizations to select Regions based on factors such as latency, compliance, data residency, and proximity to customers.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

Through the console, users can:

- Create and manage cloud resources
- Monitor applications and infrastructure
- Manage users and permissions
- View service usage
- Monitor billing and costs
- Access AWS services available in different Regions

The AWS Management Console provides access to more than 200 AWS services.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides resizable virtual servers in the AWS cloud. Organizations can use EC2 to run websites, applications, databases, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve files and other types of data. It can be used for backups, application data, media files, and large datasets.

### 3. Amazon RDS

Amazon Relational Database Service (Amazon RDS) is a managed relational database service. It simplifies database deployment, operation, scaling, and maintenance.

### 4. AWS Lambda

AWS Lambda is a serverless computing service that allows developers to run code without managing servers. Lambda can automatically scale based on incoming requests and events.

## Three Advantages

### 1. Large Service Portfolio

AWS provides a wide variety of cloud services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

### 2. Global Infrastructure

AWS has a broad global infrastructure that allows organizations to deploy applications closer to their users and design highly available systems.

### 3. Scalability and Flexibility

AWS resources can be increased or decreased according to workload requirements. This allows organizations to adapt their infrastructure as demand changes.

## Typical Enterprise Use Cases

AWS can be used by enterprises for:

- Website and application hosting
- Data backup and disaster recovery
- Enterprise databases
- Big data and analytics
- Serverless applications
- E-commerce platforms
- Artificial intelligence and machine learning
- Development and testing environments
- Hybrid and multi-cloud architectures
