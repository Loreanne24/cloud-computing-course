# CloudNova Technologies – Client Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is recommended because it offers flexible and scalable services that are suitable for startups with limited budgets. Its serverless and managed services allow the company to build and scale a mobile application without managing a large amount of infrastructure. The startup can begin with small resources and increase them as the application gains users. GCP also provides services for application hosting, databases, storage, and analytics.

### Recommended Services
- **Google Cloud Run** – Runs containerized applications without managing servers.
- **Cloud Firestore** – A scalable NoSQL database suitable for mobile and web applications.
- **Cloud Storage** – Stores images, videos, files, and other application data.
- **Firebase** – Provides mobile application development tools, authentication, analytics, and notifications.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management easier. The university can use hybrid-cloud solutions to connect its existing on-premises infrastructure with Azure. This allows the university to gradually migrate services instead of moving everything at once.

### Recommended Services
- **Azure Virtual Machines** – Hosts Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides cloud-based identity and access management and integrates with existing Active Directory environments.
- **Azure Hybrid Benefit** – Helps organizations use eligible existing Windows Server licenses in Azure.
- **Azure Storage** – Provides scalable cloud storage for university files and data.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is recommended because it provides powerful infrastructure and specialized services for Artificial Intelligence and Machine Learning workloads. Its AI infrastructure supports high-performance computing and GPU/TPU acceleration for demanding model training and inference tasks. The company can scale computing resources when large AI workloads are running and reduce resources when they are no longer needed. GCP also provides managed AI and machine learning services that can simplify the development process.

### Recommended Services
- **Google Compute Engine** – Provides customizable virtual machines with high-performance CPUs and GPUs.
- **Google Cloud TPU** – Provides specialized hardware designed to accelerate machine learning workloads.
- **Vertex AI** – Provides tools for developing, training, deploying, and managing machine learning models.
- **Google Cloud Storage** – Stores large datasets, training data, and AI model files.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

Amazon Web Services (AWS) is recommended because it provides a large global infrastructure designed for highly available and scalable applications. AWS allows the e-commerce company to distribute its application across multiple Availability Zones and regions to improve reliability. Automatic scaling services can dynamically add or remove computing resources based on customer demand. AWS also provides managed database, storage, networking, and content delivery services suitable for a multinational e-commerce platform.

### Recommended Services
- **Amazon EC2** – Provides scalable virtual servers for running the company's applications.
- **Amazon EC2 Auto Scaling** – Automatically adjusts the number of EC2 instances according to demand.
- **Elastic Load Balancing (ELB)** – Distributes incoming traffic across multiple servers to improve availability.
- **Amazon RDS** – Provides managed relational databases for e-commerce applications.
- **Amazon CloudFront** – Delivers website content quickly to customers around the world through a global content delivery network.
